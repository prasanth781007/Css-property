Document Structure

!DOCTYPE
Defines the document type and HTML version.
<!DOCTYPE html>
html
Root element of an HTML page.
<html lang="en"></html>
head
Contains meta information about the document.
<head>
    <meta charset="UTF-8">
    <title>Document Title</title>
</head>
body
Contains the visible page content.
<body>
    <h1>Hello World</h1>
</body>
meta
Defines metadata about an HTML document.
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Page description">
title
Defines the title of the document (shown in browser tab).
<title>Page Title</title>
link
Defines a link to an external resource (like CSS).
<link rel="stylesheet" href="styles.css">
style
Defines internal CSS styles.
<style>
    body {
        font-family: Arial;
    }
</style>
script
Defines client-side JavaScript.
<script>
    console.log("Hello World");
</script>
<script src="script.js"></script>

<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

p
Defines a paragraph.
<p>This is a paragraph of text.</p>

This is a paragraph of text.

div
Defines a division or section.
<div class="container">
    <p>Content inside a div</p>
</div>
pre
Defines preformatted text (preserves spaces and line breaks).
<pre>
function hello() {
    console.log("Hello World");
}
</pre>
function hello() {
    console.log("Hello World");
}
hr
Defines a thematic break or horizontal rule.
<p>Section above</p>
<hr>
<p>Section below</p>

Sectioning

header
Defines introductory content for a page or section.
<header>
    <h1>Website Title</h1>
                      
    <p>Tagline or description</p>
</header>
nav
Defines navigation links.
<nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
    <a href="/contact">Contact</a>
</nav>
Home About Contact
main
Contains the main content of the document.
<main>
    <h1>Main Content</h1>
    <p>The main content goes here.</p>
</main>
article
Defines independent, self-contained content.
<article>
    <h2>Article Title</h2>
    <p>Article content goes here...</p>
</article>

Article Title

Article content goes here...

section
Defines a section in a document.
<section>
    <h2>Section Title</h2>
    <p>Section content...</p>
</section>

Section Title

Section content...

aside
Defines content aside from the page content.
<aside>
    <h3>Related Links</h3>
    <ul>
        <li><a href="#">Link 1</a></li>
        <li><a href="#">Link 2</a></li>
    </ul>
</aside>

Related Links

  • Link 1
  • Link 2
footer
Defines a footer for a document or section.
<footer>
    <p>© 2023 My Website</p>
</footer>

© 2023 My Website

Inline Text Semantics

span
Generic inline container for styling.
<p>This is <span style="color:red">red text</span> inside a paragraph.</p>

This is red text inside a paragraph.

strong
Indicates important text (typically bold).
<p>This is <strong>important</strong> text.</p>

This is important text.

em
Emphasized text (typically italic).
<p>This is <em>emphasized</em> text.</p>

This is emphasized text.

mark
Text highlighted for reference purposes.
<p>This is <mark>highlighted</mark> text.</p>

This is highlighted text.

small
Side comments and small print.
<p>Normal text <small>Small text</small></p>

Normal text Small text

Lists

ul
Defines an unordered (bulleted) list.
<ul>
    <li>First item</li>
    <li>Second item</li>
</ul>
  • First item
  • Second item
ol
Defines an ordered (numbered) list.
<ol>
    <li>First item</li>
    <li>Second item</li>
</ol>
  1. First item
  2. Second item
dl
Defines a description list.
<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language</dd>
    <dt>CSS</dt>
    <dd>Cascading Style Sheets</dd>
</dl>
HTML
HyperText Markup Language
CSS
Cascading Style Sheets

Tables

table
Defines an HTML table.
<table>
    <caption>Monthly Sales</caption>
    <tr>
        <th>Month</th>
        <th>Sales</th>
    </tr>
    <tr>
        <td>January</td>
        <td>$100</td>
    </tr>
</table>
Monthly Sales
Month Sales
January $100

Forms

form
Defines an HTML form for user input.
<form action="/submit" method="post">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name">
    
    <label for="email">Email:</label>
    <input type="email" id="email" name="email">
    
    <button type="submit">Submit</button>
</form>

Media

img
Embeds an image in the document.
<img src="image.jpg" alt="Description of image" width="300" height="200">
audio
Embeds sound content.
<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    Your browser does not support the audio element.
</audio>
video
Embeds video content.
<video width="320" height="240" controls>
    <source src="movie.mp4" type="video/mp4">
    Your browser does not support the video tag.
</video>

Interactive Elements

details
Creates a disclosure widget with content shown only when toggled open.
<details>
    <summary>Click to see more</summary>
    <p>Hidden content that appears when expanded.</p>
</details>
Click to see more

Hidden content that appears when expanded.

dialog
Creates a dialog box or modal window.
<dialog open id="myDialog">
    <p>This is a dialog box</p>
    <button onclick="document.getElementById('myDialog').close()">Close</button>
</dialog>

This is a dialog box

Scripting

script
Defines client-side JavaScript or links to an external script file.
<script>
    document.getElementById("demo").innerHTML = "Hello JavaScript!";
</script>

<script src="script.js"></script>
noscript
Defines alternative content for users without client-side scripting.
<noscript>
    <p>Your browser does not support JavaScript!</p>
</noscript>
